How it works

Bring your connections
to the same PC.

Connect the PC to Wi-Fi, then connect phones by USB. Turn on USB tethering on Android, or Personal Hotspot on iPhone and tap “Trust” if prompted. Windows needs Apple Devices or iTunes installed for iPhone USB tethering. Boost measures each adapter’s receive rate and can split direct downloads across them when the server supports byte ranges.

01

Connect

Use home Wi-Fi plus USB-tethered Android phones or iPhones on one Windows PC.

02

Paste a link

Enter a direct file download URL in Donut Boost and choose where to save the file.

03

Download together

For eligible direct file links, view file progress and transfer speed while selected adapters fetch separate byte ranges.

In the app: choose Combine Both, Home Wi-Fi Only, or Mobile Data Only; set custom download speed limits (or uncapped); toggle individual connections; pause, resume, or cancel a download; and choose its save folder.

Torrents: paste a magnet link or choose a `.torrent` file. Donut Boost shows metadata-based size, verified completion progress, measured peer speed, and ETA. Torrent traffic follows the Windows default route; adapter bonding is currently available for supported direct HTTP downloads only. Port forwarding is disabled, and Donut Boost stops the torrent when it completes.

Adapter rates are measured from Windows network counters and include all traffic on each adapter, not only Donut Boost. By default, Windows keeps its existing route. If USB tethering makes Windows switch away from home Wi-Fi, use Prefer Wi-Fi in the app; Windows asks for administrator approval and Donut saves the previous metrics so you can restore them. The preference lasts until restored or Windows restarts. This keeps Wi-Fi as the normal system route while Donut's own direct downloads can still use selected adapters. Game launchers are not routed or bonded by Donut Boost.

Setup help: Android USB tethering · iPhone Personal Hotspot on Windows. Multi-connection speed depends on the server supporting byte-range downloads. Links without that support may not benefit from combined connections and can fail.
